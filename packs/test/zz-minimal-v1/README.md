# ZZ — a fictional jurisdiction (test pack)

**ZZ is not a country. "Zzedonia Accounting Act No. 1 of 2001" is not a
law. Nothing here describes a real chart of accounts.** If you arrived
here looking for a jurisdiction's real rules, you want
`packs/ro/omfp1802-v1/` (Romania, OMFP 1802/2014),
`packs/hu/actc2000-v1/` (Hungary, Act C of 2000) or
`packs/intl/ifrs-captions-v1/` (the generic IFRS-caption pack).

## Why it exists

This pack is the payload of the **N7 acceptance gate**,
`tests/engine/test_new_jurisdiction.py`. N7 turns the architecture claim

> adding a minimal new jurisdiction = authoring a pack (+ optionally a
> front-end), with **zero** engine code changes

from a convention into a test. It runs a fictional ZZ trial balance
(`tests/engine/fixtures/zz_minimal_tb.csv`) through the real production
path — front-end parse → LedgerDoc IR → `classify` → the pack's bound
checks → the canonical builder → `stage_persist` (auto-reconcile seam) →
`served_canonical_bs` → `FactsGateway` — and then asserts that the whole
ZZ change-set lives under `packs/` and `tests/`, and that `src/engine`
contains no ZZ-specific branch anywhere.

If a future contributor admits a jurisdiction by editing `src/engine`
instead of authoring a pack, N7 fails.

## Why it lives under the real `packs/` root

Pack **discovery** is what admits a jurisdiction, so the gate has to
exercise the real discovery rather than a fixture root. Two consequences
worth knowing:

* This directory ships wherever `packs/` ships (the backend image
  `COPY`s `packs/`).
* Any surface that offers "every jurisdiction that has a pack" will
  offer ZZ. That is the honest reading of a deployed pack. ZZ classifies
  nothing on its own: it is reachable only when a caller *explicitly*
  names jurisdiction `ZZ`, never by content detection.

## Also: the worked example

`docs/ADDING_A_JURISDICTION.md` walks a first-time pack author through
these five files line by line. They are hand-authored (not generated by
a `scripts/port_*_pack.py` frozen generator) precisely so they read as
data rather than as generator output.
