## 1. Scope

F5.0 turns CFO AI from a financial-analysis display tool into a teaching
one. Every number, ratio, chart, and red flag becomes a three-layer
drill-down the user controls:

- **Layer 1 (Glance)** — formatted value + sentiment cue. Always visible,
  no interaction.
- **Layer 2 (Hover/Tap)** — concept name, ~80-150 word definition, inline
  formula, benchmark micro-bar, sentiment-tinted narrative. One click.
- **Layer 3 (Deep Dive)** — full sheet: formula visualization, source-
  account trace, peer comparison, historical trend, Opus-generated personal
  narrative, related concepts. Second click.

Design references locked at session start: **Apple-quality interactions,
Stripe Docs-level clarity, Khan Academy-level pedagogy, Linear-level
smoothness.** No clutter — learning surfaces appear on demand, never in
the way.

**Pacing.** 5 phases. 1 session per phase except Phase 4 (1-2 sessions).
Total budget 5-6 sessions to F5.0 v1 ship. Mid-phase stops are normal;
phase-skipping is forbidden.

**Out of scope** — see §7.

## 5. Per-Step Stop Discipline (inherited from F3.16)

F5.0 inherits F3.16's per-phase stop protocol. **No phase-skipping.
No "fast proceed full" overrides.** The discipline produced:

- 26+ cent matches across 8 RAS fixtures
- Zero production regressions
- 4 documented closure invariants (a, b, c, F-A3.2-CROSS-PATH)
- 15 Locks (+ sub-rules) as durable improvements

The same discipline applies to F5.0. Specifically:

- **Stop and surface** any prediction-vs-observation mismatch after a
  phase ships (Lock #8)
- **Stop and surface** any concept whose `getSentiment` doesn't
  discriminate on Lock #12's wrong-on-purpose synthetic inputs
- **Stop and surface** any per-surface learning code that should have
  lived in the concept library (Lock #11)
- **Stop and ask** when a concept's narrative requires data the runtime
  doesn't expose yet — don't fabricate

The stop discipline is not a velocity tax. It IS the velocity.

## 6. Pre-Locked Predictions (Lock #8 placeholder)

Each phase's session-1 plan-doc must end with an explicit **Pre-Ship
Predictions** block, structured per Lock #8:

```
For Phase <N>, I predict:
  - <verifiable claim 1>, e.g. "Bundle size delta < 15 KB"
  - <verifiable claim 2>, e.g. "popover open-time < 100 ms on iPhone SE"
  - <verifiable claim 3>, e.g. "TS clean across 0 new strict errors"
  - <other invariants>

Empirical backing for each prediction:
  - <evidence>: bundle measurement from prior FE deploy, vite analyzer
  - <evidence>: existing popover open-time on a similar Radix surface
  - <evidence>: TS strict-mode results on the closest existing primitive
```

**No framework-consistency reasoning.** A prediction of the form
"the concept library is well-typed, therefore Phase 1 will TS-clean"
is exactly what Lock #8 forbids. The empirical backing must come from
running the type-check against a partial implementation OR a
documented analogous prior result (Risk Radar Step 7 FE work +
mobile-consolidation Phase 1 primitives are good analogues).

## 7. What's NOT in Scope

F5.0 is **the interactive learning surface for existing financial
metrics**. Explicitly out of scope, file as separate sprints if needed:

- A/B testing infrastructure for the learning surface (product analytics
  sprint, not F5.0)
- Real-time concept editing UI (concepts are PR-managed; runtime editor
  is a later product surface)
- Multi-tenant concept overrides / white-label customization
- Concept versioning / history / audit log (Phase 5 may add a "concept
  last updated" timestamp; full history is post-F5.0)
- Anything outside the financial-metric domain — no HR / legal /
  marketing concepts
- Mobile-native app (web only; F5.0 ships responsive)
- Anthropic API key acquisition (operator-side; uses Lock #15 three-field
  convention when filed in SAGA)
- Concept content for non-RAS country packs (concepts assume Romanian
  RAS + Western GAAP semantics; SKR03 / HU / BG packs add their own
  concepts post-launch)

**If the operator asks for any of the above during F5.0, file as a new
sprint in SAGA §9 and continue with the financial-learning scope only.**
