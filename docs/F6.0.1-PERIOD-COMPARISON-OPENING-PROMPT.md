# F6.0.1 — Period Comparison Everywhere (Opening Prompt)

F6.0 Phase 1 — Period Comparison Everywhere. This is the foundation for variance analysis (F6.0.3) and scenarios (F6.0.5). Get it right; everything downstream depends on the multi-period infrastructure built here.

Per F6.0-FPA-INITIATIVE-OPENING-PROMPT.md, F5.0 Phase 2-5 has closed and F3.16 Bug #4 is in stable holding pattern. If either condition isn't true, STOP and check before proceeding.

## What this phase ships

A globally-available period selector at the top of every financial page that controls a comparison axis. Every numeric value on the page renders both the primary period's number AND the delta vs the comparison period. Variance (absolute and percentage) shows alongside the value.

Default comparison: "Latest vs Prior Year."

Available comparisons:
- vs Prior Year (same period last year)
- vs Prior Period (immediately preceding period in the dataset)
- vs Budget (only available if a Budget-tagged dataset exists)
- YTD vs YTD Prior Year
- QoQ (this quarter vs same quarter last year)
- None (single-period view, current behavior)

This phase does NOT ship:
- Variance analysis as a dedicated view (that's F6.0.3)
- Dataset tagging UI (Budget vs Actual vs Prior Year — that's F6.0.3)
- What-if modeling (that's F6.0.5)
- Three-statement linking (that's F6.0.6)

Stay in scope. The temptation will be to ship variance analysis "while we're in here." Push back. Variance gets its own phase with its own verification gates.

## ARCHITECTURAL FOUNDATION — period store

Single source of truth for what's being compared, globally available. Every financial component subscribes to it.

```ts
// src/stores/period.ts
import { create } from 'zustand';
import { persist } from 'zustand/middleware';

export type ComparisonMode =
  | 'none'              // single period view
  | 'prior_year'        // same period one year ago
  | 'prior_period'      // immediately preceding period
  | 'budget'            // vs Budget-tagged dataset (when available)
  | 'ytd_vs_ytd_prior'  // YTD this year vs YTD same date last year
  | 'qoq';              // same quarter prior year

export interface PeriodState {
  // Primary period — usually the latest available
  primaryDatasetId: string | null;

  // Comparison
  comparisonMode: ComparisonMode;
  comparisonDatasetId: string | null;  // resolved at selection time, cached

  // Actions
  setPrimary: (datasetId: string) => void;
  setComparisonMode: (mode: ComparisonMode) => void;
  setComparisonDataset: (datasetId: string | null) => void;
  reset: () => void;

  // Derived helpers
  hasComparison: () => boolean;
}

export const usePeriodStore = create<PeriodState>()(
  persist(
    (set, get) => ({
      primaryDatasetId: null,
      comparisonMode: 'prior_year',
      comparisonDatasetId: null,

      setPrimary: (datasetId) => {
        set({ primaryDatasetId: datasetId });
        // Re-resolve comparison whenever primary changes
        resolveComparison(get().comparisonMode, datasetId);
      },

      setComparisonMode: (mode) => {
        set({ comparisonMode: mode });
        resolveComparison(mode, get().primaryDatasetId);
      },

      setComparisonDataset: (datasetId) => set({ comparisonDatasetId: datasetId }),

      reset: () => set({
        primaryDatasetId: null,
        comparisonMode: 'prior_year',
        comparisonDatasetId: null
      }),

      hasComparison: () => {
        const s = get();
        return s.comparisonMode !== 'none' && s.comparisonDatasetId !== null;
      },
    }),
    {
      name: 'cfo-ai-period',
      // Persist preference across sessions but re-resolve on hydrate
      partialize: (s) => ({ comparisonMode: s.comparisonMode }),
    }
  )
);

// Helper — resolve which dataset is the comparison given the mode + primary
async function resolveComparison(mode: ComparisonMode, primaryId: string | null) {
  if (!primaryId || mode === 'none') {
    usePeriodStore.setState({ comparisonDatasetId: null });
    return;
  }

  const primary = await getDatasetById(primaryId);
  if (!primary) return;

  const allDatasets = await getAllDatasetsForUser();

  let comparison: Dataset | null = null;

  switch (mode) {
    case 'prior_year':
      // Find dataset with period_end exactly 12 months before primary
      comparison = findDatasetByPeriodEnd(
        allDatasets,
        subtractMonths(primary.periodEnd, 12)
      );
      break;

    case 'prior_period':
      // Find immediately preceding dataset (could be quarter, month, year depending on cadence)
      comparison = findPrecedingDataset(allDatasets, primary);
      break;

    case 'budget':
      // Find a dataset tagged as Budget for the same period
      // NOTE: dataset tagging UI ships in F6.0.3. For Phase 1, treat as null unless
      // an existing dataset has metadata.kind === 'budget'
      comparison = allDatasets.find(
        d => d.metadata?.kind === 'budget' && d.periodEnd === primary.periodEnd
      ) ?? null;
      break;

    case 'ytd_vs_ytd_prior':
      // YTD same fiscal year start to primary period end, vs YTD same range last year
      comparison = findDatasetByPeriodRange(
        allDatasets,
        subtractMonths(primary.periodStart, 12),
        subtractMonths(primary.periodEnd, 12)
      );
      break;

    case 'qoq':
      // Same quarter prior year
      comparison = findDatasetByPeriodEnd(
        allDatasets,
        subtractMonths(primary.periodEnd, 12)
      );
      break;
  }

  usePeriodStore.setState({ comparisonDatasetId: comparison?.id ?? null });
}
```

Critical: the store persists ONLY the user's preferred comparison MODE across sessions. The actual comparison dataset is re-resolved every time the primary dataset changes. This prevents stale comparison-dataset bugs when the user uploads a new period.

## CONCEPT CONTEXT EXTENSION — dual values

The F5.0 ConceptContext currently holds one period's values. Extend it to hold primary + comparison values for every field:

```ts
// src/lib/learning/conceptContext.ts
export interface ConceptContext {
  // Primary period — existing fields, no breaking changes
  datasetId: string | null;
  periodEnd: string | null;
  reportingCurrency: 'RON' | 'EUR' | 'USD';
  industryId: string | null;
  revenue: number;
  cogs: number;
  // ... all existing fields ...

  // NEW — comparison period
  comparison: ComparisonContext | null;
}

export interface ComparisonContext {
  mode: ComparisonMode;
  datasetId: string;
  periodEnd: string;
  label: string;  // human-readable e.g. "FY2024" or "Q3 2024"

  // Same shape as the primary fields, but for the comparison period
  revenue: number;
  cogs: number;
  // ... all the same derived fields ...

  // Pre-computed deltas (faster than computing on every render)
  delta: {
    revenue: { absolute: number; pct: number };
    cogs: { absolute: number; pct: number };
    ebitda: { absolute: number; pct: number };
    ebitdaMargin: { absolute: number; pct: number };  // pct here is pp (percentage points)
    // ... every comparable field
  };
}
```

The `ConceptContextProvider` reads from BOTH datasets when comparison is active:

```tsx
// src/lib/learning/ConceptContextProvider.tsx
export function ConceptContextProvider({ children }: { children: ReactNode }) {
  const primaryTB = useDatasetStore(s => s.activeTrialBalance);
  const { comparisonDatasetId, comparisonMode } = usePeriodStore();
  const comparisonTB = useTrialBalance(comparisonDatasetId);  // hook fetches by ID
  const benchmark = useBenchmarkStore(s => s.currentBenchmark);

  const context = useMemo(() => {
    const primary = buildConceptContext(primaryTB);

    if (!comparisonTB || comparisonMode === 'none') {
      return { ...primary, comparison: null };
    }

    const cmp = buildConceptContext(comparisonTB);
    const delta = computeDeltas(primary, cmp);

    return {
      ...primary,
      comparison: {
        mode: comparisonMode,
        datasetId: comparisonTB.datasetId,
        periodEnd: comparisonTB.periodEnd,
        label: formatPeriodLabel(comparisonTB, comparisonMode),
        ...cmp,
        delta,
      },
    };
  }, [primaryTB, comparisonTB, comparisonMode, benchmark]);

  return (
    <ConceptContextContext.Provider value={context}>
      {children}
    </ConceptContextContext.Provider>
  );
}

function computeDeltas(primary: ConceptContext, comparison: ConceptContext): DeltaMap {
  const delta = (a: number, b: number) => ({
    absolute: a - b,
    pct: b === 0 ? null : (a - b) / Math.abs(b),
  });

  return {
    revenue: delta(primary.revenue, comparison.revenue),
    cogs: delta(primary.cogs, comparison.cogs),
    ebitda: delta(primary.ebitda, comparison.ebitda),
    // EBITDA margin is a percentage; the delta is in PERCENTAGE POINTS, not percentage
    ebitdaMargin: {
      absolute: primary.ebitdaMargin - comparison.ebitdaMargin,
      pct: null  // percentage-of-percentage is misleading; don't compute
    },
    // ... every field
  };
}
```

Critical math discipline: **delta of a ratio is in percentage points, not percentage**. If EBITDA margin moved from 12% to 14%, the delta is +2pp (percentage points), NOT +16.7%. Mixing these up is the most common variance-analysis bug in finance software. The type system signals this by setting `pct: null` for ratio deltas — the UI then knows to render "+2pp" not "+X%".

### Mobile considerations
- Selector scrolls horizontally if it overflows (`overflow-x-auto scrollbar-none`)
- Each interactive element has `min-h-[32px]` (compact but tappable on small screens; sits above the 44px default because the parent has padding making the effective tap area larger)
- Comparison label truncates intelligently — "Prior Year" not "Same Period One Year Earlier"

## NUMERIC RENDERING — delta-aware Money + Percentage components

The `<Money>` and `<Percentage>` components need to render comparison context when present. Three rendering modes:

```tsx
// src/components/Money.tsx — extend existing component
interface MoneyProps {
  amount: number;
  currency?: string;
  sourceCurrency?: string;
  compact?: boolean;

  // NEW — comparison context
  comparison?: {
    amount: number;
    mode: ComparisonMode;
    showDelta?: boolean;  // default true if comparison provided
    showAbsolute?: boolean;  // show "+3.2M" vs "+5.4%"
  };

  // Display variant
  variant?: 'default' | 'large' | 'compact' | 'inline';
}

export function Money({ amount, currency = 'RON', comparison, variant = 'default', ...rest }: MoneyProps) {
  const formatted = formatValue(amount, currency, variant);

  // No comparison — render as before
  if (!comparison) {
    return <span className="tabular-nums whitespace-nowrap">{formatted}</span>;
  }

  const delta = amount - comparison.amount;
  const pctDelta = comparison.amount !== 0 ? delta / Math.abs(comparison.amount) : null;
  const sentiment = delta > 0 ? 'positive' : delta < 0 ? 'negative' : 'neutral';

  return (
    <span className="inline-flex items-baseline gap-2 tabular-nums whitespace-nowrap">
      <span>{formatted}</span>
      {comparison.showDelta !== false && (
        <DeltaBadge
          delta={delta}
          pctDelta={pctDelta}
          sentiment={sentiment}
          showAbsolute={comparison.showAbsolute}
          currency={currency}
        />
      )}
    </span>
  );
}

function DeltaBadge({ delta, pctDelta, sentiment, showAbsolute, currency }: Props) {
  return (
    <span className={cn(
      'inline-flex items-center gap-0.5',
      'px-1.5 py-0.5 rounded-md',
      'text-[10px] font-medium tabular-nums',
      sentiment === 'positive' && 'bg-accent/10 text-accent',
      sentiment === 'negative' && 'bg-danger/10 text-danger',
      sentiment === 'neutral' && 'bg-white/[0.04] text-text-dim',
    )}>
      {delta > 0 ? '↑' : delta < 0 ? '↓' : '·'}
      {pctDelta !== null && !showAbsolute ? (
        <span>{Math.abs(pctDelta * 100).toFixed(1)}%</span>
      ) : (
        <Money amount={Math.abs(delta)} sourceCurrency={currency} compact variant="compact" />
      )}
    </span>
  );
}
```

Same pattern for `<Percentage>` — but with critical math discipline: deltas on ratios are PERCENTAGE POINTS, not percentage:

```tsx
// src/components/Percentage.tsx
export function Percentage({ value, comparison, ...rest }: Props) {
  if (!comparison) {
    return <span className="tabular-nums">{formatPct(value)}</span>;
  }

  // CRITICAL: delta of a percentage is in PP, not %
  // 14% vs 12% = +2pp (NOT +16.7%)
  const deltaPP = value - comparison.value;
  const sentiment = deltaPP > 0 ? 'positive' : deltaPP < 0 ? 'negative' : 'neutral';

  return (
    <span className="inline-flex items-baseline gap-2 tabular-nums">
      <span>{formatPct(value)}</span>
      <span className={cn(
        'text-[10px] font-medium px-1.5 py-0.5 rounded-md',
        sentiment === 'positive' && 'bg-accent/10 text-accent',
        sentiment === 'negative' && 'bg-danger/10 text-danger',
      )}>
        {deltaPP > 0 ? '+' : ''}{deltaPP.toFixed(1)}pp
      </span>
    </span>
  );
}
```

## LEARNING POPOVER — comparison context flows through

The F5.0 popover automatically gets comparison context because it reads from `ConceptContext`. Update the popover header to show the delta inline:

```tsx
// src/components/learning/LearningPopover.tsx — extend PopoverValueBlock
function PopoverValueBlock({ conceptKey, value, ctx }: Props) {
  const comparison = ctx.comparison;
  const conceptDelta = comparison?.delta[conceptKey];  // typed safely

  return (
    <div className="px-5 py-5">
      <div className="text-3xl font-light tabular-nums tracking-tight leading-none">
        <FormattedValue value={value} />
      </div>

      {comparison && conceptDelta && (
        <div className="mt-3 inline-flex items-center gap-2 px-2.5 py-1 rounded-full bg-white/[0.04] text-xs">

              ? `${conceptDelta.absolute > 0 ? '+' : ''}${(conceptDelta.pct * 100).toFixed(1)}%`

            }
          </span>
          <span className="text-text-faint">vs {comparison.label}</span>
        </div>
      )}
    </div>
  );
}
```

```ts
describe('Period comparison math', () => {
  it('computes EBITDA delta correctly across two real datasets', () => {
    // Use real Scandia FY2024 and FY2025 fixtures
    const fy2024 = loadFixture('scandia_fy2024.json');
    const fy2025 = loadFixture('scandia_fy2025.json');

    const primary = buildConceptContext(fy2025);
    const comparison = buildConceptContext(fy2024);
    const delta = computeDeltas(primary, comparison);

    expect(delta.revenue.absolute).toBeCloseTo(primary.revenue - comparison.revenue, 2);
    expect(delta.revenue.pct).toBeCloseTo((primary.revenue - comparison.revenue) / Math.abs(comparison.revenue), 4);
  });

  it('EBITDA margin delta is in percentage points, not percentage', () => {
    // 14% vs 12% must produce +2pp delta with pct=null
    const primary = { ebitdaMargin: 0.14 } as ConceptContext;
    const comparison = { ebitdaMargin: 0.12 } as ConceptContext;
    const delta = computeDeltas(primary, comparison);

    expect(delta.ebitdaMargin.absolute).toBeCloseTo(0.02, 4);  // 2pp
    expect(delta.ebitdaMargin.pct).toBeNull();  // percent-of-percent is misleading
  });

  it('handles zero-denominator gracefully', () => {
    const primary = { revenue: 100 } as ConceptContext;
    const comparison = { revenue: 0 } as ConceptContext;
    const delta = computeDeltas(primary, comparison);

    expect(delta.revenue.absolute).toBe(100);
    expect(delta.revenue.pct).toBeNull();  // never divide by zero
  });

  it('resolves prior_year comparison correctly when matching dataset exists', async () => {
    const datasets = [
      { id: 'a', periodEnd: '2025-12-31' },
      { id: 'b', periodEnd: '2024-12-31' },
      { id: 'c', periodEnd: '2023-12-31' },
```
